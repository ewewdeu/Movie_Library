## Описание программы

Movie Library — это современное графическое приложение для управления личной коллекцией фильмов. Программа предоставляет удобный интерфейс для организации, поиска и хранения информации о просмотренных или планируемых к просмотру фильмах.

### Основные возможности:

#### Управление фильмами:
- **Добавление** новых фильмов с полной информацией:
  - Название фильма
  - Жанр (драма, комедия, фантастика и др.)
  - Год выпуска (от 1888 до текущего года)
  - Рейтинг по 10-балльной шкале
- **Просмотр** всей коллекции в удобной таблице
- **Удаление** ненужных записей из библиотеки

#### Фильтрация и поиск:
- **По жанру** — быстрый поиск фильмов определенного жанра
- **По году выпуска** — поиск фильмов за конкретный год
- **Комбинированная фильтрация** — одновременный поиск по жанру и году
- **Сброс фильтров** — возврат к полному списку одним кликом

#### Хранение данных:
- **Автоматическое сохранение** в формате JSON
- **Загрузка данных** при запуске программы
- **Портативность** — все данные в одном файле `movies.json`
- **Человекочитаемый формат** — JSON легко просмотреть в любом редакторе

#### Валидация данных:
- **Год выпуска** — проверка, что введено число от 1888 до текущего года
- **Рейтинг** — проверка диапазона от 0.0 до 10.0
- **Название** — проверка на пустое значение
- **Понятные сообщения** об ошибках с подсказками

### Особенности интерфейса:
- **Современный дизайн** в темных тонах
- **Цветовая индикация рейтинга**:
  - Зеленый — высокий рейтинг (≥7.5)
  - Желтый — средний рейтинг (5.0-7.4)
  - Красный — низкий рейтинг (<5.0)
- **Счетчик фильмов** — показывает общее количество
- **Статус-бар** — информирует о действиях
- **Адаптивный интерфейс** — растягивается под размер окна
